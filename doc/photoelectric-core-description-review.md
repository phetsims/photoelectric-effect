## 7. Implementation Footprint

Where each "Will implement" request landed in the code, to help judge its complexity and cost. Measured on branch `features/photoelectric-effect/issues/250` (uncommitted working tree, Sep 30, 2026) against `main`.

**How lines are counted**

- A line is one added (+) or removed (−) line in `git diff`. A modified line counts as one of each. Comments, JSDoc, imports and blank lines count, because they are part of the work.
- *TS* is TypeScript under `js/`. *yaml* is `photoelectric-effect-strings_en.yaml`, which holds every spoken string. File paths below are relative to `photoelectric-effect/`.
- The files that `grunt modulify` generates from the yaml are not counted: `js/PhotoelectricEffectFluent.ts`, `js/PhotoelectricEffectStrings.ts` and `photoelectric-effect-strings_en.json` (+461/−254 together).
- Each changed line was assigned to the request that required it, including its supporting imports and comments and the removal of code the request made unused. An independent second pass checked every assignment, and a script confirmed that every changed line is counted exactly once.
- Some lines serve more than one request, such as the shared "is ejecting" state that RD-1, RD-5 and RD-6 all read. These are counted in full for each request and marked *shared*, so the per-request numbers add up to more than the overall total.
- *Where* gives line ranges in the updated files (`L`). For lines that were deleted, it gives their position in `main` ("removed from HEAD L…"). Line numbers will drift as the files change.

**Overall:** +511/−250 hand-written lines across 33 files (TS +349/−145, yaml +162/−105).
